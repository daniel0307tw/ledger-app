# categories 句型模型

## 實體概述

- **性質**: Aggregate（category）；供 ledger_transaction 參照（category_id），未來預算報表依此分組統計
- **攜帶狀態**: id, name, type(收入/支出/皆可)
- **Invariant 清單**: 無（名稱不強制唯一，比照 account）；type 必須為 收入/支出/皆可 其一，且為必要參數

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 建立分類 | Creation | name, type | id, name, type | MISSING_FIELD |
| 查詢分類列表 | Query | （無） | id, name, type | （無） |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | 系統中有以下分類： | aggregate-given | id, name, type |
| W1 | When | 使用者建立分類： | command | name, type |
| W2 | When | 使用者查詢分類列表 | query | （無） |
| T1 | Then | 操作失敗，錯誤為"<violation>"（引用系統抽象 S-T1） | success-failure | violation |
| T2 | Then | 操作成功 | success-failure | （無） |
| T3 | Then | 應建立一個分類： | aggregate-then | id, name, type |
| T4 | Then | 查詢結果應包含以下分類： | readmodel-then | id, name, type |

## 測試分析

### 建立分類

**等價類劃分**: 名稱提供 vs 未提供；type 提供 vs 未提供
**邊界值分析**: 不適用（自由字串，無長度限制規格）
**狀態轉移**: 不適用
**組合覆蓋**: 不適用
**錯誤推測**: 不適用（名稱不強制唯一，無重複衝突需要驗證；type 若提供不合法值屬 schema 層驗證，比照既有 transaction.type 慣例不在 BDD 層另立 Rule）

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 缺少分類名稱時操作失敗 | （無） | name 缺漏, type="支出" | 失敗(MISSING_FIELD) | 等價類 |
| 2 | 缺少收支類型時操作失敗 | （無） | name="健身房", type 缺漏 | 失敗(MISSING_FIELD) | 等價類 |
| 3 | 建立後應新增一個分類 | （無） | name="健身房", type="支出" | 成功，分類已建立 | 等價類 |

### 查詢分類列表

**等價類劃分**: 系統剛初始化（僅 20 個預設分類）vs 使用者已自行新增額外分類
**邊界值分析**: 不適用
**狀態轉移**: 不適用
**組合覆蓋**: 不適用
**錯誤推測**: 不適用

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 查詢結果應包含系統預先建立的 20 個預設分類 | （無，隨系統初始化即存在） | （無） | 成功，結果含 20 筆預設分類，各自標明 type：17 筆 type=支出（餐飲、日常用品、交通、水電瓦斯、電話網路、居家、服飾、汽車、娛樂、美容美髮、交際應酬、學習深造、保險、稅金、醫療、轉帳手續費 共 16 筆 + 校正回歸 type=皆可 共 17 筆），另 3 筆 type=收入（薪資、獎金、投資） | 等價類 |
| 2 | 查詢結果應包含使用者自行新增的分類 | 分類「健身房」（type=支出）已存在（額外新增） | （無） | 成功，結果包含「健身房」type=支出 | 等價類 |
