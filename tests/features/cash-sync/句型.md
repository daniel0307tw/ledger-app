# cash-sync 句型模型

## 實體概述

- **性質**: Aggregate（ledger_transaction，共用既有實體，本輪新增 is_stock_sync / currency 欄位）
- **攜帶狀態**: date, amount, currency(TWD/USD), category_id(null), account_id, type(收入/支出), is_transfer(true), is_stock_sync(true)
- **Invariant**（本輪新增）:
  - is_stock_sync=true 的交易必為 is_transfer=true 且 category_id=null
  - is_stock_sync=true 的交易建立/更新/刪除皆不觸發 sync_to_cash_position() / cancel_previous_sync()

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 接收股票交易建立記帳交易 | Creation | direction(支出/收入), amount, currency, account_name | id, is_stock_sync, is_transfer, category_id, currency | 找不到該帳戶、必要參數未提供 |
| 接收股票交易更新記帳交易 | Mutation | id, amount, direction | amount, type | 找不到該筆收支紀錄 |
| 接收股票交易刪除記帳交易 | Mutation | id | （無，驗證交易已不存在） | 找不到該筆收支紀錄 |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | `系統中有以下帳戶：`（沿用系統抽象共用句型 S-G1） | aggregate-given | 帳戶集合 |
| G2 | Given | `系統中有以下收支紀錄：`（Data Table：id, account_id, amount, type, is_stock_sync） | aggregate-given | 既有交易集合 |
| W1 | When | `stock_analyzer 推送以下現金異動：`（Data Table：direction, amount, currency, account_name） | command (When, Mutation) | 新交易參數 |
| W2 | When | `stock_analyzer 推送更新現金異動 "<id>"：`（Data Table：amount, direction） | command (When, Mutation) | id, 更新參數 |
| W3 | When | `stock_analyzer 推送刪除現金異動 "<id>"` | command (When, Mutation) | id |
| T1 | Then | `操作成功，結果符合：`（Data Table：is_stock_sync, is_transfer, category_id, currency） | readmodel-then | 建立結果欄位 |
| T2 | Then | `操作失敗，錯誤為"<violation>"`（沿用系統抽象共用句型 S-T1） | success-failure | violation |
| T3 | Then | `不應觸發 CashPosition 同步` | aggregate-then (States Verify，查測試替身是否被呼叫) | 無 |
| T4 | Then | `收支紀錄 "$交易.id" 應已不存在` | aggregate-then (States Verify) | 交易 id |

## 測試分析

### 操作 1：接收股票交易建立記帳交易

**等價類劃分**：帳戶存在 vs 不存在；方向 支出 vs 收入；幣別 TWD vs USD。

**邊界值分析**：不適用（金額本身的邊界值驗證屬於既有 amount>0 規則，非本輪新增行為，跳過）。

**狀態轉移**：不適用（Creation，無前置狀態）。

**組合覆蓋**：方向與幣別相互獨立，各取 1 行代表即可覆蓋兩個維度，不需窮舉 2×2。

**錯誤推測**：帳戶名稱打錯字/不存在。

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 支出方向、TWD，建立成功且不觸發 CashPosition 同步 | （無，Background 已有帳戶） | direction=支出, amount=100100, currency=TWD, account_name=永豐銀行 | 成功，is_stock_sync=true, is_transfer=true, category_id=null, currency=TWD；不觸發 CashPosition 同步 | 等價類（支出+TWD） |
| 2 | 收入方向、USD，建立成功 | （無） | direction=收入, amount=495, currency=USD, account_name=新光銀行 | 成功，currency=USD，其餘同上 | 等價類（收入+USD） |
| 3 | 帳戶不存在時操作失敗 | （無） | account_name=凱基銀行（不存在） | 失敗，錯誤為"找不到該帳戶" | 錯誤推測 |

### 操作 2：接收股票交易更新記帳交易

**等價類劃分**：id 對應到 is_stock_sync=true 交易 vs 不存在 vs 存在但 is_stock_sync=false（使用者手動記帳）。

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | is_stock_sync=true 交易更新成功且不觸發同步 | 交易 "T1" 已存在，is_stock_sync=true, amount=100100, type=支出 | id=T1, amount=200000, direction=收入 | 成功，交易更新為 amount=200000, type=收入；不觸發 CashPosition 同步 | 等價類（存在且為 stock_sync） |
| 2 | id 不存在時操作失敗 | （無） | id=NOT-EXIST | 失敗，錯誤為"找不到該筆收支紀錄" | 等價類（不存在） |
| 3 | id 存在但非 stock_sync 交易時操作失敗 | 交易 "T2" 已存在，is_stock_sync=false（使用者手動記帳） | id=T2 | 失敗，錯誤為"找不到該筆收支紀錄" | 等價類（存在但非 stock_sync，安全檢查） |

### 操作 3：接收股票交易刪除記帳交易

**等價類劃分**：同操作 2。

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | is_stock_sync=true 交易刪除成功且不觸發同步取消 | 交易 "T3" 已存在，is_stock_sync=true | id=T3 | 成功，交易已不存在；不觸發 cancel_previous_sync | 等價類（存在且為 stock_sync） |
| 2 | id 不存在時操作失敗 | （無） | id=NOT-EXIST | 失敗，錯誤為"找不到該筆收支紀錄" | 等價類（不存在） |
| 3 | id 存在但非 stock_sync 交易時操作失敗 | 交易 "T4" 已存在，is_stock_sync=false | id=T4 | 失敗，錯誤為"找不到該筆收支紀錄" | 等價類（安全檢查） |
