# 系統抽象

## 實體清單

| 實體 | 性質 | 攜帶狀態摘要 | 對應 features subfolder |
|------|------|-------------|------------------------|
| ledger_transaction | Aggregate | date, amount, category_id, note, account_id, type(收入/支出), is_transfer, transfer_group_id, sync_status, cash_position_id, source_recurring_transaction_id, advance_payment_amount（交易總金額中屬於代墊款的部分，非整筆旗標）, advance_payment_status(pending/settled), settlement_transaction_id | transactions |
| account | Aggregate | id, name, type(一般帳戶/信用卡) | accounts |
| category | Aggregate | id, name, type(收入/支出/皆可) | categories |
| cloud_invoice | Aggregate | invoice_number(unique), invoice_date, amount, seller_name, item_summary, status(pending_review/synced/skipped), transaction_id | cloud-invoices |
| recurring_transaction | Aggregate | frequency(每天/每週/每月/每季/每年/每三年), amount, category_id, account_id, type, note, start_date, generate_count, status(啟用/停用) | recurring-transactions |
| budget | Aggregate | scope(總預算/分類預算), category_id, monthly_amount | budgets |

## 操作全景

| 操作 | 所屬實體 | 行為分類 | 輸入參數 | 回傳型別 |
|------|---------|---------|---------|---------|
| 新增收支紀錄 | ledger_transaction | Creation | date, amount, category_id, account_id, type, note? | 建立的 transaction |
| 編輯收支紀錄 | ledger_transaction | Mutation | id, date, amount, category_id, account_id, type, note? | 更新後的 transaction |
| 刪除收支紀錄 | ledger_transaction | Mutation | id | （無） |
| 查詢收支紀錄 | ledger_transaction | Query | start_date, end_date | transaction 列表 |
| 建立帳戶 | account | Creation | name, type | 建立的 account |
| 查詢帳戶列表 | account | Query | （無） | account 列表（含 type、balance） |
| 帳戶間轉帳 | ledger_transaction（成對） | Creation | from_account_id, to_account_id, amount, date | 建立的兩筆 transaction |
| 建立分類 | category | Creation | name, type | 建立的 category |
| 查詢分類列表 | category | Query | （無） | category 列表（含 20 個預設分類，含 type） |
| 查詢分類花費統計 | ledger_transaction | Query | start_date, end_date | 依分類分組的支出統計列表（category, total_amount） |
| 查詢資產總覽 | account（+ 外部股票持倉資料） | Query | （無） | 現金/信用卡總額 + 股票個股明細 + 幣別（TWD/USD）資產小計 |
| 同步雲端發票 | cloud_invoice（+ ledger_transaction） | Creation（批次） | invoices[]（每筆：invoice_number, invoice_date, amount, seller_name, item_summary?） | 逐筆處理結果（已建立/待確認/已略過/資料錯誤） |
| 查詢待確認雲端發票清單 | cloud_invoice | Query | （無） | pending_review 狀態的發票列表 + 各自相似的既有交易資訊 |
| 處理待確認雲端發票 | cloud_invoice（+ ledger_transaction） | Mutation | id, decision(確認為新交易/確認為重複), account_id?, category_id? | 更新後的 cloud_invoice（+ 若確認為新交易則建立的 transaction） |
| 查詢雲端發票同步健康狀態 | cloud_invoice | Query | （無） | 最後成功同步時間、累計待確認/已同步/批次內錯誤筆數 |
| 建立固定收支規則 | recurring_transaction（+ ledger_transaction） | Creation | frequency, amount, category_id, account_id, type, note?, start_date, generate_count | 建立的規則 + 立即生成的 generate_count 筆 transaction |
| 編輯固定收支規則 | recurring_transaction | Mutation | id, frequency, amount, category_id, account_id, type, note?, start_date, generate_count | 更新後的規則（不影響已生成的交易） |
| 刪除固定收支規則 | recurring_transaction | Mutation | id | （無，已生成的交易保留） |
| 查詢固定收支規則列表 | recurring_transaction | Query | （無） | 規則列表（含啟用/停用） |
| 補生成固定收支交易 | recurring_transaction（+ ledger_transaction） | Mutation | id | 本次補生成的筆數與交易列表（差額計算：generate_count − 已生成期數） |
| 建立預算 | budget | Creation | scope, category_id?, monthly_amount | 建立的預算 |
| 編輯預算 | budget | Mutation | id, monthly_amount | 更新後的預算 |
| 刪除預算 | budget | Mutation | id | （無） |
| 查詢預算列表 | budget | Query | （無） | 預算列表（總預算+各分類預算） |
| 查詢預算執行狀況 | budget（+ ledger_transaction） | Query | （無，範圍固定為當月） | 各預算的上限/已花費/剩餘/是否超支 |
| 確認收到還款 | ledger_transaction（成對，代墊款+還款） | Mutation | id, date, amount（等於代墊金額）, account_id | 更新後的代墊款 transaction（已結清，總金額不變）+ 新建立的還款 transaction（金額=代墊金額） |
| 查詢待收回代墊款清單 | ledger_transaction | Query | （無） | advance_payment_amount 不為 null 且 advance_payment_status=pending 的 transaction 列表 |

## 系統前置狀態拆解

> 從所有操作的 Rule（前置）反推，系統狀態由哪些可獨立建置的部件組成。

| 部件 | 資料型別 | 建置方式 | 內部子結構 | Given 句型 |
|------|---------|---------|-----------|-----------|
| 帳戶 | Data Table | Data Table（含 type，未指定時預設 一般帳戶） | 無 | `Given 系統中有以下帳戶：` |
| 分類 | Data Table | Data Table（另有 20 筆系統預設 seed data，非 per-scenario Given，隨系統初始化即存在） | 無 | `Given 系統中有以下分類：` |
| 收支紀錄 | Data Table | Data Table | 依賴帳戶已存在（account_id 參照）、依賴分類已存在（category_id 參照，且分類 type 須與交易 type 相符或分類 type=皆可） | `Given 系統中有以下收支紀錄：` |
| 外部股票持倉資料 | External API Response（唯讀，非本地 Data Table，來自 stock_analyzer 新增的唯讀 API） | Data Table 形式注入測試替身回應 / 明確宣告為空 / 明確宣告服務不可連線 | 無（不屬於本專案任何資料表，Phase 05 以 HTTP client 測試替身模擬） | `Given stock_analyzer 有以下股票持倉：` / `Given stock_analyzer 尚無任何股票持倉` / `Given stock_analyzer 的股票資料查詢服務暫時無法連線` |
| 雲端發票同步紀錄 | Data Table | Data Table（含 status，未指定時預設 pending_review） | 無 | `Given 系統中有以下雲端發票同步紀錄：` |
| 固定收支規則 | Data Table | Data Table | 依賴帳戶已存在、依賴分類已存在 | `Given 系統中有以下固定收支規則：` |
| 預算 | Data Table | Data Table | scope=分類預算時依賴分類已存在 | `Given 系統中有以下預算：` |

## 行為分類與句型骨架

### Creation

**When 句型模板**：
  `When 使用者建立{operation}：`（接 Data Table）

**Then 句型模板（成功）**：
  `Then 操作成功，結果符合：`（接 Data Table）

**Then 句型模板（失敗）**：
  `Then 操作失敗，錯誤為"<violation>"`

### Mutation

**When 句型模板**：
  `When 使用者{operation} $entity.id：`（接 Data Table，刪除操作無 Data Table）

**Then 句型模板（成功）**：
  `Then 操作成功`（+ 視操作補充 States Verify）

**Then 句型模板（失敗）**：
  `Then 操作失敗，錯誤為"<violation>"`

### Query

**When 句型模板**：
  `When 使用者查詢{operation}：`（接 Data Table 或無參數）

**Then 句型模板（成功）**：
  `Then 操作成功，查詢結果應包含：`（接 Data Table）

## 共用契約

### Postcondition 模式

- 新增／轉帳成功 → 建立 1（或 2）筆 ledger_transaction，若帳戶需要同步則連動嘗試寫入外部 CashPosition
- 編輯／刪除成功 → 更新／移除該筆 ledger_transaction，若先前已同步或待重試，連動更新／取消 CashPosition 同步任務

### Violation 模式

| 前置條件失敗 | 錯誤訊息 |
|-------------|---------|
| 收支紀錄不存在 | `找不到該筆收支紀錄` |
| 帳戶不存在 | `找不到該帳戶` |
| 分類不存在 | `找不到該分類` |
| 分類收支類型與交易類型不符 | `分類收支類型與交易類型不符` |
| 必要欄位缺漏 | `必要參數未提供` |
| 金額非正數 | `金額必須為正數` |
| 轉出/轉入帳戶相同 | `轉出帳戶與轉入帳戶不可相同` |
| 查詢區間起訖顛倒 | `起始日期不可晚於結束日期` |
| 雲端發票缺必要欄位（invoice_number/invoice_date/amount/seller_name） | `發票資料缺少必要欄位` |
| 處理已非 pending_review 狀態的雲端發票 | `此筆發票已處理過` |
| 固定收支規則不存在 | `找不到該固定收支規則` |
| 提前生成期數非正整數 | `提前生成期數必須為正整數` |
| 預算不存在 | `找不到該預算` |
| 分類已有分類預算（重複建立） | `此分類已設定過預算` |
| 總預算已存在（重複建立） | `總預算已存在` |
| 代墊金額設定用於收入交易 | `代墊款標記僅限支出交易` |
| 代墊金額超過交易總金額 | `代墊金額不可超過交易總金額` |
| 欲確認收到還款的交易不含代墊金額 | `該筆交易非代墊款交易` |
| 欲確認收到還款的代墊款交易已結清 | `該筆代墊款已結清` |
| 還款金額與代墊金額（非交易總金額）不符 | `還款金額與代墊金額不符，僅支援全額還款` |

## 共用句型

> 2 個 domain（transactions、accounts）共用以下句型，Single Source of Truth 在此，各 domain 句型.md 引用。

| # | 類別 | 句型 | 用途 |
|---|------|------|------|
| S-G1 | Given | `系統中有以下帳戶：`（Data Table: id, name, type） | 兩個 domain 皆需要先有帳戶 |

## 變異點索引

| 實體 | 特有行為 | 需要的專屬句型類別 |
|------|---------|------------------|
| ledger_transaction | 依 type 決定同步到外部 CashPosition 的方向（Withdraw/Deposit） | CashPosition 同步狀態驗證句型 |
| ledger_transaction | 轉帳一次產生兩筆成對紀錄，且不計入收支報表 | 轉帳專屬 When/Then 句型 |
| ledger_transaction | 編輯/刪除需處理待重試中的同步任務 | 同步狀態轉移驗證句型 |
| account（資產總覽） | 唯一具備「部分失敗（partial failure）」語意的查詢——外部股票資料來源查詢失敗時，整體查詢仍視為操作成功，只是結果中股票部分標示失敗，不走既有「操作失敗」句型 | partial failure 標示句型（assets domain 專屬） |
| account（資產總覽） | ledger-app 的 account 無 currency 欄位，現金/信用卡負債恆為 TWD；USD 幣別小計僅由美股市值構成，不含任何現金分量 | 幣別小計句型需明確標註此推導依據，非 GAP |
| cloud_invoice（同步雲端發票） | 批次操作，逐筆獨立處理三種結果（已建立/待確認/已略過），單一 When 觸發多筆 Then 驗證——既有 domain 皆為單筆操作，無先例可循，屬本輪新變異點 | 批次逐筆結果驗證句型（Then 需接受一個「結果列表」而非單一結果） |
| cloud_invoice（同步雲端發票） | 呼叫端是外部系統 Hermes（非「使用者」），Given/When 主詞需反映此差異 | Hermes 專屬 When 句型（`When Hermes 傳送以下雲端發票資料進行同步：`），與既有「使用者」句型並存不衝突 |
| recurring_transaction（建立規則） | 建立當下副作用是同時產生多筆 ledger_transaction（1 個 When 觸發 N 筆交易），且交易日期可能在未來 | Then 需驗證「生成筆數」與「各筆日期」，既有 domain 的新增操作僅產生 1 筆 |
| recurring_transaction（補生成） | 差量計算語意（只補不足期數），需要「已有 X 期、設定 Y 期、應補 Y-X 期」的 Given/Then 搭配 | 差量驗證句型，本輪新變異點 |
| budget（查詢執行狀況） | 查詢結果需要即時比對 ledger_transaction 當月實際花費，是唯一「跨兩個 Aggregate 即時聚合計算」的 Query（既有查詢分類花費統計已有類似聚合先例，可比照） | 沿用既有分類花費統計聚合句型的設計精神，非全新變異點 |
| ledger_transaction（確認收到還款） | 一次操作同時變更兩筆紀錄的狀態——更新既有代墊款交易（標記已結清，總金額不變）+ 建立新的還款交易（金額=代墊金額，不是原交易總金額），且兩者互相關聯（settlement_transaction_id）；跟轉帳的「一次建立兩筆新紀錄」不同，這裡是「一筆既有的 + 一筆新的」 | 雙紀錄關聯驗證句型（Then 需同時驗證新建立的還款交易內容，以及原代墊款交易的狀態變化） |
| ledger_transaction（代墊款部分排除統計） | 排除效果是**部分且有條件的**：一筆交易的總金額可能只有一部分是代墊款（例如總額 4000、代墊 3000、自己消費 1000），未結清時整筆總金額計入統計，結清後計入統計的有效金額變成「總金額－代墊金額」，不是整筆排除為 0；跟 is_transfer 的「無條件、整筆排除」完全不同 | 部分金額排除驗證句型（區別於既有 is_transfer 的整筆無條件排除句型），需要能表達「總金額－代墊金額」這種算式結果 |
